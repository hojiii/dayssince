# 며칠째

아무 날짜나 넣으면 그날부터 며칠째인지 세어주는 미니앱이에요.

결과를 한꺼번에 보여주지 않고 하나씩 공개해요. 이름이 먼저 뜨고, 큰 숫자가 0부터
굴러가며 올라가고, 그다음 다음 기념일까지 며칠 남았는지가 나와요. 같은 정보라도
한꺼번에 쏟으면 그냥 표가 되고, 하나씩 나오면 기다리는 시간이 생겨요.

"더 알아보기"를 누르면 같은 기간을 다른 단위로 바꿔 보여줘요. 몇 시간인지, 심장이
몇 번 뛰었을지, 달이 지구를 몇 바퀴 돌았는지까지요.

## 개발

```bash
npm install
npm run dev     # 개발 서버
npm test        # 날짜 계산 테스트
npm run build   # 번들 빌드 (.ait)
```

`.env`에 광고 그룹 ID와 인앱 상품 productId를 넣어야 광고와 결제가 켜져요.
`.env.example`을 참고하세요. 값이 비어 있으면 광고와 구매 버튼이 자동으로 숨겨져요.
